# Captures des expériences Noces

Captures historiques de Littlest Tokyo, Inakaya et Kinkakuji, sur téléphone (320px) et tablette (820px). Les suffixes numériques indiquent la progression dans le parcours ; `temple` et `reduced` identifient la carte finale et une vue en réduction des mouvements.

Le dossier a été renommé avec les composants Noces le 9 octobre 2026. Les images sont conservées à l'identique ; elles ne valident pas les modifications ultérieures, notamment les capteurs du téléphone. L'état courant est décrit dans [PROJECT_STATE.md](../../PROJECT_STATE.md) et les [modèles Noces](../../NOCES_MODELS.md).
