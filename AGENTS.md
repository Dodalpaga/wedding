# Project instructions

## Documentation

Project knowledge is maintained in `/docs`.

- `docs/ARCHITECTURE.md`: current system architecture
- `docs/DECISIONS.md`: important technical decisions and rationale
- `docs/PROJECT_STATE.md`: current implementation state and known issues
- `docs/plans/`: implementation plans for substantial work

Keep these documents synchronized with significant changes.

For complex features or major refactors, create an execution plan
under `docs/plans/active/` and update it as implementation progresses.
Move completed plans to `docs/plans/completed/`.
